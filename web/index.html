Reading the numbers

API time
The sum of the model's response times across all calls. Nothing else is included. This is the fair column for comparing speed.
Wall
Clock time from Start to finish. Includes API time plus every Wikipedia fetch (two per hop), the watch delay you set, and any wait when Wikipedia rate-limits with a 429. It tells you how long the race felt, not how fast the model was.
Watch delay
A pause after each decision, for viewing only, so you can see the chosen link and the probabilities before the page moves on. It adds to Wall and to nothing else. Set it to 0 for a timed run, 3 or 4 seconds to narrate.
Calls
How many times the model was asked. Usually equals hops. It is higher when a chosen link looped back, was skipped, or the lane backtracked.
Cost
Model cost only, computed from list prices per token. Wikipedia is free.
Conf on Jev
Computed from the shape of the probability distribution the model returns. Probability concentrated on one link means high confidence, spread across several means low. The model is trained so these probabilities match outcomes.
Conf on Claude
A number between 0 and 1 the model wrote in its JSON answer when asked how sure it was. The API exposes no probabilities, so this is the model's opinion of itself.
Conf on GPT
The probability of the answer string, measured from token logprobs. Because the answer is forced into a JSON schema, this collapses to about 1.00 and is not a useful signal. The self-reported number is shown in brackets when it differs. GPT-5 models refuse logprobs, so they fall back to self-reported only.
Mean conf
Average of the per-decision confidence for that lane. The three lanes measure different things, so do not compare this column across lanes.
